# yolk
## 1. cd: electron
## 2. npm install
## 3. build: npm run dist
## 4: dev: npm run dev

## 安装 react
安装react的命令
```shell
npm install react react-dom
npm install --save-dev @types/react @types/react-dom
```
## 开发环境下面运行
```shell
npm run build
npm run dev
```

## 项目打包

1. 运行 python 下面的build.exe.bat
2. 运行shell: 
````shell
npm run build:dev
````
